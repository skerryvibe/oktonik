# OKTONIK 0.1.0-rc.4 — Public preview

**Harmonic performance instrument · by Skerry Vibe**

Live chords, adaptive melody and independent bass on Ableton Move / Schwung.
Five focused pages: **PLAY, CHORD, MELODY, BASS and MIDI**.

## New since rc.2

- **Eight controls directly on PLAY:** KEY, SCALE, EXT, OCT, SPRD, LEAD,
  STRUM and SUST, identical to CHORD. The Chord Map stays visible; touching or
  turning a knob shows its parameter and value in the footer.
- **More readable chord names:** longer names use two lines at the original
  font size. Short names retain their single-line layout. Very long names
  still show `~` when truncated.
- Updated illustrated guide and in-module help. No settings schema change.

## Install

Download **oktonik-public-0.1.0-rc.4.tar.gz** from Assets below. Back up projects,
upload the compressed archive through Schwung at `move.local:7700`, restart
Move and select **OKTONIK**. Do not install GitHub's Source code archives.

[Illustrated user guide](https://github.com/skerryvibe/oktonik/blob/main/docs/oktonik-public.md) ·
[Report a bug](https://github.com/skerryvibe/oktonik/issues)

Existing OKTONIK settings are retained. This preview focuses on live performance,
not sequencing: no ARP, sequencer, recording, Capture or separate IDEAS mode.
