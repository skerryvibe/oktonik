# Beta.16 – STRUM-test på Move

Installera modularkivet via Schwung och starta om Move.

Öppna STRUM med CHORDS ratt 7 eller bläddra en sida framåt från CHORDS.

1. GAP 20 ms, TIME 0%, VEL 0%: jämför UP och DOWN.
2. ALT: spela separata ackordanslag och lyssna på växlande riktning.
3. RAND: tonordningen varierar utan att andra toner läggs till.
4. TIME 20–40% och VEL 10–25%: prova samma ackord med olika padanslag.
5. GAP 0 ger samtidig start; velocityvariation kan fortfarande användas.
6. Byt inställningar medan ett ackord hålls: ingen ny attack ska utlösas.
7. Med SUST OFF, släpp snabbt under ett långsamt strum: väntande toner avbryts.
   Med HOLD spelas de vidare; med PEDAL avbryts väntande toner medan redan
   spelade toner följer instrumentets pedal. STOP ska alltid avsluta allt.
8. Kontrollera basgest, melody och ARP: de ska inte få strumvariation.

LEAD kan behålla gemensamma toner utan nya anslag. Testa först med LEAD OFF
för att höra riktningen tydligt. Det här är inte gitarrvoicings ännu.
Sparade steps behåller strumparametrarna; slumpade detaljer dras på nytt vid varje spelning.
