# Beta.13 – speltest

Installera beta.13-arkivet via Schwung och starta om Move.
Ingen installation eller ändring har gjorts på din Move automatiskt.

- PLAY: håll C och välj Em som basgest. Rubriken visar C/E men rutorna
  visar fortfarande C, Dm, Em osv. Modifier-preview fungerar som tidigare.
- CHORDS: KEY, SCALE, EXT, OCT / SPRD, LEAD, STRUM, SUST.
- BASS: BASS, B.OCT, B.VEL, B.NTE / GEST.
- MIDI: fyra par utgång/kanal för ackord, melodi, bas och ARP.
- ARP: aktivera ARP. Välj FREE på A.CLOCK, ställ BPM, låt Move vara stoppad
  och spela ett ackord. Testa HOLD av/på och STOP. SUST HOLD kan också hålla
  ackordkällan aktiv; välj SUST OFF när du testar stopp vid padsläpp.
- A.CLOCK SYNC: kontrollera att dagens transportstyrda beteende finns kvar.
- SEQ är tidigare LOOP: Shift + step sparar, Delete + step raderar,
  RUN + Move Play spelar den sparade följden. FREE startar inte SEQ.
- Äldre separat sekvensutgång bevaras och visas enbart då som SEQ OUT.
  Välj ackordens utgång där för att ta bort undantaget.

Sparformatet är fortfarande schema 7. Gamla projekt får SYNC och 120 BPM
som utgångsvärden, utan att befintliga musikaliska inställningar ersätts.
FREE behöver fortfarande verifieras på fysisk Move.
