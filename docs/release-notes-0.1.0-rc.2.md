# OKTONIK 0.1.0-rc.2

Harmonic performance instrument — by Skerry Vibe.

Live chords, adaptive melody and bass, with five focused pages. Public includes
harmonic modifiers, Bass Gesture, per-pad editing, sustain and simple strum.

rc.2 introduces separate OKTONIK / OKTONIK Lab identities and saves, consistent
branding and removal of IDEAS from Public. Lab retains experimental features.

Upload the Public tar.gz through Schwung and restart Move. Back up first.
Both profiles can be installed and independently import existing schema-7
Chord Pilot projects when their own save file is absent. Original files are
untouched; profile settings are not continuously synchronized.

Public has no IDEAS, ARP, sequencer, recording or Capture. Hardware acceptance
testing remains required. Report profile/version, Move/Schwung versions,
MIDI routes/channels, sustain settings and reproduction steps with any issue.
