# OKTONIK 0.1.0-rc.2

Harmonic performance instrument — by Skerry Vibe.

Live chords, adaptive melody and bass, with five focused pages. Public includes
harmonic modifiers, Bass Gesture, per-pad editing, sustain and simple strum.

rc.2 introduces the OKTONIK identity and consistent branding. This preview is
about playing and discovering harmony live, not programming chord sequences.

**[Illustrated user guide](https://github.com/skerryvibe/oktonik/blob/main/docs/oktonik-public.md)** ·
[Report a bug](https://github.com/skerryvibe/oktonik/issues)

Upload the Public tar.gz through Schwung and restart Move. Back up first.
OKTONIK imports valid schema-7 Chord Pilot project data only when its own save
file is absent. Original files remain untouched; settings are not continuously
synchronised. Choose **oktonik-public-0.1.0-rc.2.tar.gz** from Assets, not the
automatically generated Source code archives.

Public has no IDEAS, ARP, sequencer, recording or Capture. Hardware acceptance
testing remains required. Report version, Move/Schwung versions,
MIDI routes/channels, sustain settings and reproduction steps with any issue.

211 JavaScript tests and 45 DSP behavioural test groups pass; hardware coverage
is not exhaustive. This is a **prerelease**, not a final stability claim.

## In development

Richer harmonic suggestions, expressive strum/patterns and ways to capture

have no promised release date. Our priority is a reliable live instrument.
